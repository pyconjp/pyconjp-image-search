# 顔検索の高速化（Voronoi パーティション）

顔検索では 73,000 件以上の顔ベクトル（512 次元）を検索対象としますが、Voronoi 分割による事前フィルタリングにより検索候補を約 4% に絞り込み、検索速度を高速化しています。

## 仕組み

### 概要

256 個のセントロイド（代表ベクトル）を使って、顔の特徴空間を 256 の領域（パーティション）に分割します。検索時はクエリに近いパーティションだけを探すことで、全件スキャンを回避します。

### データ準備時（オフライン）

各顔の Embedding を 256 個のセントロイドと比較し、最も近い **2 個** のパーティション ID を保存します。

```
顔A → [14, 52]
顔B → [14, 128]
顔C → [66, 197]
```

### クエリ時（検索時）

1. クエリの顔 Embedding を 256 個のセントロイドと比較し、上位 **5 個** のパーティション ID を取得
2. データ側の 2 個とクエリ側の 5 個に **1 つでも重なり** があれば候補とする（`list_has_any`）
3. 候補に残った顔のみコサイン類似度で正確にランキング

```
クエリ顔 → [14, 52, 128, 66, 5]

顔A [14, 52]  → 14 が一致 → 候補
顔B [14, 128] → 14, 128 が一致 → 候補
顔C [66, 197] → 66 が一致 → 候補
顔D [230, 77] → 一致なし → スキップ
```

### なぜデータ側 2 個、クエリ側 5 個か

| | 個数 | 理由 |
|---|---|---|
| データ側 | 2 | ストレージ節約（全 73,248 顔に保存） |
| クエリ側 | 5 | 検索漏れ（recall）を減らすため広めに候補を拾う |

### 理論的な候補率

均等分布を仮定した場合の計算:

```
P(重なる) = 1 - C(251, 2) / C(256, 2) = 3.88%
簡易近似: 2 x 5 / 256 = 3.91%
```

実データでは分布の偏りにより約 4〜5% 程度になります。

## セントロイドデータ

`data/voronoi_pivots.json` に 256 個のセントロイド（512 次元）が保存されています。このファイルは別プロジェクト（[image-vector-poc](https://github.com/cmscom/image-vector-poc)）の notebook 102 で KMeans により生成された事前学習データです。

Web アプリ用に `web/public/voronoi_pivots.json` にも同じファイルが配置されています。セントロイドを更新した場合は両方のファイルを更新してください。

## パーティション割り当ての実行

顔データが追加・更新された場合、以下のスクリプトで各顔にパーティション ID を再割り当てします。

```bash
uv run scripts/assign_voronoi_partitions.py [--force]
```

| オプション | デフォルト | 説明 |
|-----------|-----------|------|
| `--db` | `pyconjp_image_search.duckdb` | DuckDB ファイルパス |
| `--centroids` | `data/voronoi_pivots.json` | セントロイド JSON ファイル |
| `--n-assign` | `2` | 各顔に割り当てるパーティション数 |
| `--force` | - | 既存の割り当てを上書き再計算 |

実行すると `face_detections` テーブルの `voronoi_partition_ids` カラムが更新されます。

## Firestore への反映

Firestore にデータを投入する場合、`voronoi_partition_ids` も自動的にアップロードされます。

```bash
uv run scripts/upload_to_firestore.py [--force]
```

## Web アプリでの動作

- **デフォルト**: Voronoi 検索（上位 5 パーティションに絞り込み後、コサイン類似度で順位付け）
- **全件スキャン**: 顔検索実行後に表示されるチェックボックスで切り替え可能
- 検索結果メッセージに「(Voronoi)」または「(全件スキャン)」と表示されます
- DuckDB モード・Firestore モードの両方で Voronoi 検索が動作します
